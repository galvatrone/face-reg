# FaceReg

[English version / Английская версия](README.md)

FaceReg — это офлайн-проект на Python для распознавания лиц, построенный на `OpenCV` и `face_recognition` (`dlib`).
Он получает кадры с веб-камеры, находит лица, сравнивает их с локальной базой и старается сохранять устойчивую идентичность одного и того же человека, даже если распознавание временно становится нестабильным.

Проект ориентирован на практическое использование:
- автоматическое создание нового UUID для неизвестных лиц
- сохранение первого фото лица и дополнительных снимков
- постепенное накопление новых `encoding` для одного и того же человека
- глобальный лог и отдельный лог-файл для каждого ID
- несколько режимов запуска для разного железа и разных углов камеры

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python low_main.py
# или
python main.py
# или
python ceiling_main.py
```

## Режимы программы

### `low_main.py`

Это самая лёгкая версия.
Она предназначена для слабых компьютеров, старых ноутбуков или машин с небольшим количеством ядер CPU.

Основные характеристики:
- самый простой пайплайн
- самая низкая нагрузка на CPU
- наименее агрессивные настройки детекции
- лучший вариант, если нужно минимизировать лаги

Компромисс:
- ниже точность на расстоянии
- хуже работает на сложных углах лица
- менее устойчива к кратким сбоям распознавания

Используй этот режим, если:
- компьютер слабый
- камера смотрит почти фронтально
- плавность интерфейса важнее максимального качества детекции

### `main.py`

Это основной повседневный режим.
Он выносит тяжёлую детекцию лиц и вычисление `encoding` в отдельный процесс через `multiprocessing`, поэтому окно камеры и основной цикл работают заметно плавнее.

Основные характеристики:
- сбалансированный режим по скорости и качеству
- меньше визуальных лагов, чем в лёгкой однопроцессной версии
- лучше восстанавливает трек при кратких пропусках благодаря удержанию лиц и таймауту видимости
- лучший выбор по умолчанию для обычного использования

Компромисс:
- потребляет больше CPU, чем `low_main.py`
- всё ещё оптимизирован в основном под более обычные углы камеры, а не самые сложные верхние ракурсы

Используй этот режим, если:
- у тебя нормальный современный CPU
- нужен лучший универсальный режим
- камера находится примерно на уровне лица или слегка наклонена

### `ceiling_main.py`

Это тяжёлый режим, настроенный под сложные углы.
Он предназначен для более проблемных камер, особенно потолочных или сильно наклонённых, которые смотрят сверху и сбоку.

По сравнению с `main.py` этот режим:
- использует более крупный масштаб детекции
- запускает детекцию чаще
- дольше удерживает треки при кратких провалах распознавания
- использует более сильную предобработку для сложного света и маленьких лиц
- проверяет несколько повернутых версий кадра, чтобы лучше находить лица под углом
- может запрашивать более высокое разрешение камеры для дальних лиц

Компромисс:
- самая высокая нагрузка на CPU
- работает медленнее остальных режимов
- более тяжёлый пайплайн, потому что обрабатывает несколько повёрнутых вариантов кадра

Используй этот режим, если:
- камера установлена высоко
- люди попадают в кадр под углом
- лица маленькие из-за расстояния
- точность на сложной геометрии важнее скорости

## Импорт фото

`import_foto_p.py` импортирует лица из папок с фотографиями в локальную базу.

Как это работает:
- создай папку `foto_p/`
- внутри неё создай по одной подпапке на человека
- имя подпапки станет именем человека
- каждое валидное фото внутри папки используется для построения `encoding`

Пример:

```text
foto_p/
  Misha/
    1.jpg
    2.jpg
  Alex/
    a.jpg
    b.jpg
```

Поведение импорта:
- если такого имени ещё нет, создаётся новый UUID
- если имя уже есть, скрипт добавляет новые `encoding` к существующему человеку
- валидные фото копируются в `faces/<user_id>/`
- превью с рамкой вокруг лица сохраняются в `foto_p_result/<person_name>/`
- фото без лиц или с несколькими лицами пропускаются

Запуск:

```bash
python import_foto_p.py
```

## Структура данных

- `known_faces.pkl` — локальная база лиц с именами и `encoding`
- `faces/<user_id>/` — сохранённые изображения лиц для каждого человека
- `logs/` — отдельные лог-файлы для каждого человека
- `log.txt` — глобальный лог событий
- `foto_p/` — исходные папки для пакетного импорта фото
- `foto_p_result/` — превью после импорта с рамками вокруг лица

## Управление

Во время работы с веб-камерой:
- `q` — выход
- `w` — переименовать ID
- `d` — удалить ID и связанные файлы

## Как выбрать режим

Используй `low_main.py`, если компьютер слабый и нужна минимальная нагрузка.

Используй `main.py`, если нужен лучший универсальный режим и хороший баланс между скоростью и стабильностью.

Используй `ceiling_main.py`, если камера установлена высоко, под углом или смотрит на людей сверху и сбоку.
