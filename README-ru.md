# FaceReg

[English version / Английская версия](README.md)

FaceReg — это офлайн-проект для распознавания лиц на Python (`OpenCV` + `face_recognition`) с Java desktop UI для запуска режимов, просмотра камеры и управления локальной базой лиц.

Проект ориентирован на локальное практическое использование:
- распознавание лиц с веб-камеры без облака
- локальная база в `known_faces.pkl`
- автоматическое создание ID для неизвестных лиц
- накопление дополнительных снимков и `encoding`
- отдельные логи по каждому ID и общий лог
- Java UI для запуска режимов и управления базой

## Что есть в проекте

- Python-режимы в `src/`
- Java Swing UI в `UI/`
- пакетный импорт фото
- очистка слишком похожих векторов
- утилиты для `rename / delete / merge`

## Установка

### Python

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Java

Для UI нужен JDK, а не только JRE.

## Быстрый старт

### Запуск Java UI

```bash
javac UI/*.java
java UI.base
```

Java UI умеет:
- запускать и останавливать Python-режимы
- показывать камеру внутри окна через `mainJV.py`
- показывать последние строки логов
- переименовывать, удалять, объединять и оптимизировать ID

### Запуск Python напрямую

```bash
python src/low_main.py
# или
python src/main.py
# или
python src/ceiling_main.py
# или
python src/mainJV.py
```

## Режимы Python

### `src/low_main.py`

Самый лёгкий режим для слабых машин.

Подходит, если:
- CPU слабый
- угол камеры простой
- минимальная нагрузка важнее максимального качества

### `src/main.py`

Основной сбалансированный режим.

Использует `multiprocessing`, поэтому тяжёлая детекция и вычисление `encoding` вынесены в отдельные процессы.

Подходит, если:
- нужен лучший универсальный режим
- у тебя обычный современный CPU
- камера примерно на уровне лица

### `src/ceiling_main.py`

Более тяжёлый режим для сложных углов.

Подходит, если:
- камера установлена высоко
- лица дальше и меньше
- люди попадают в кадр сверху или под сильным углом

### `src/mainJV.py`

Специальный режим для Java UI.

Он не открывает отдельное окно OpenCV, а записывает:
- `ui_frames/mainJV_frame.jpg`
- `ui_frames/mainJV_status.txt`

Java UI читает эти файлы и показывает камеру прямо внутри своего окна.

## Java UI

Java UI находится в `UI/` и служит основной панелью управления.

Основные возможности:
- запуск `src/mainJV.py`, `src/main.py`, `src/low_main.py`, `src/ceiling_main.py`
- запуск утилит импорта и оптимизации
- показ камеры из `mainJV.py`
- показ последних строк `log.txt`
- корректная остановка Python-процессов и их дочерних worker-процессов

Основные кнопки:
- `Run` — запускает выбранный режим
- `Stop` — останавливает запущенный Python-режим и его дочерние процессы
- `Optimize` — запускает `src/check.py`
- `Rename` — переименовать ID в базе
- `Delete` — удалить ID и связанные локальные файлы
- `Merge` — объединить дубликат с основным профилем через окно выбора
- `Close` — закрыть UI и очистить временные UI-файлы

## Утилиты для базы лиц

### Импорт фото

```bash
python src/import_foto_p.py
```

Ожидаемая структура:

```text
foto_p/
  PersonA/
    1.jpg
    2.jpg
  PersonB/
    photo1.jpg
```

Что делает импорт:
- создаёт новый ID, если человека ещё нет
- добавляет новые `encoding`, если человек уже есть
- копирует принятые фото в `faces/<user_id>/`
- сохраняет превью с рамками в `foto_p_result/<person_name>/`

### Управление ID

```bash
python src/manage_faces.py rename <id> "<новое имя>"
python src/manage_faces.py delete <id>
python src/manage_faces.py merge <duplicate_id> <target_id>
```

### Оптимизация дубликатов векторов

```bash
python src/check.py
```

Этот скрипт проверяет каждый ID отдельно и удаляет слишком похожие дублирующиеся `encoding`, чтобы уменьшить размер базы.

## Структура проекта

- `UI/` — Java Swing UI
- `src/` — Python-скрипты
- `src/compare_tools/` — инструменты сравнения
- `known_faces.pkl` — локальная база лиц
- `faces/` — сохранённые фото лиц по ID
- `logs/` — отдельные логи по ID
- `log.txt` — общий лог
- `foto_p/` — исходные фото для импорта
- `foto_p_result/` — результаты импорта с рамками
- `ui_frames/` — временные кадры для Java UI

## Управление в Python-режимах с окном камеры

Для режимов, которые всё ещё открывают окно OpenCV:
- `q` — выход
- `w` — переименовать ID
- `d` — удалить ID

## Важно

- База лиц и фото хранятся локально.
- Логи, фото, временные кадры и `known_faces.pkl` не должны уходить в Git.
- `.gitignore` настроен так, чтобы игнорировать эти автоматически создаваемые данные.

## Как лучше использовать проект

- Используй Java UI, если хочешь управлять всем из одного окна.
- Используй `src/mainJV.py`, если хочешь видеть камеру внутри Java UI.
- Используй `src/main.py`, если нужен лучший универсальный прямой Python-режим.
- Используй `src/low_main.py`, если важна меньшая нагрузка.
- Используй `src/ceiling_main.py`, если камера стоит высоко или под сложным углом.
